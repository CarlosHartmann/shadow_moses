This step rebuilds the full context of every comment in the finalised datasets (the post and the surrounding comment thread), so that each comment can be read in the conversation it was written in.

Contexts are found through a separate index of the subreddits. That index was built from ../07-unique-usernames-and-subreddits/unique_subreddits.txt as of 2026-10-16 (kept as indexed_subreddits.txt there). After the indexing had been set up and started, the filtering and grouping of commenters was changed again (2026-10-17). These changes added comments to the cross-subreddit data of age_X and age_old, and those comments come from six subreddits that are not in the index: ClassicMoviePosters, NichirenBuddhism, SeattleHistory, fightingillini, letters and seattlehobos (listed in ../07-unique-usernames-and-subreddits/subreddits_not_yet_indexed.txt).

These nine comments were first given hand-made contexts in a folder "manual". It then turned out that the six subreddits are in the index after all (they were indexed later), so the nine comments are handled like all others, and the folder was removed (2026-11-16).
